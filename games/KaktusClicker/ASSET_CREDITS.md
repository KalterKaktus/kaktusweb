# KaktusClicker Asset Credits

Grafiken für den Cozy-Look. Das Spiel hat seit dem Redesign kein Audio mehr.

Die Rohbilder liegen **nicht** im Repo (`tools/raw/` ist gitignored). Optimiert
werden sie mit `python tools/optimize-assets.py`; dort stehen auch die Zielgrößen.

## Kaktus — `assets/cactus/cactus.webp`

Kawaii Cactus PNGs by [Vecteezy](https://www.vecteezy.com/free-png/kawaii-cactus)

**Wichtig:** Die Vecteezy-Free-Lizenz verlangt eine *sichtbare* Attribution auf
der Seite, auf der das Bild verwendet wird — eine Datei im Repo reicht nicht.
Der Link steht deshalb zusätzlich im Einstellungen-Tab des Spiels
(`.asset-credits` in der `index.html`). **Nicht entfernen.**

## Hintergründe und Währungen

`assets/background/desert-desktop.webp`, `desert-mobile.webp`,
`assets/currencies/coin.webp`, `nopal.webp`

Eigenmaterial des Betreibers, mit ChatGPT generiert. Keine Attribution nötig,
keine Drittlizenz. Deshalb nennt die Fußnote im Spiel **nur** den Kaktus.
