# KaktusClicker Asset Credits

Grafiken für den Cozy-Look. Audio-Credits stehen separat in `AUDIO_CREDITS.md`.

## Kaktus

Kawaii Cactus PNGs by [Vecteezy](https://www.vecteezy.com/free-png/kawaii-cactus)

**Wichtig:** Die Vecteezy-Free-Lizenz verlangt eine *sichtbare* Attribution auf
der Seite, auf der das Bild verwendet wird — eine Datei im Repo reicht nicht.
Der Link steht deshalb zusätzlich im Zusatzmenü des Spiels.

(Das unterscheidet sich von den Audio-Assets: Pixabay verlangt keine
Attribution, dort genügt die Datei.)
